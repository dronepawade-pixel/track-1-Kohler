# KOHLER AI BATHROOM DESIGNER

## MASTER PROJECT DESCRIPTION AND AI DEVELOPMENT PROMPT

You are contributing to a high-end web application called the KOHLER AI Bathroom Designer & Planner.

This is a single-developer project. The developer works across multiple devices using the same GitHub repository. Different AI models, coding harnesses, skills and development tools may be used on different devices.

The GitHub repository is the shared source of truth.

Work must therefore be feature-based and repository-aware. Do not assume that a feature belongs permanently to a particular developer or device.

Before making changes:

1. Pull or inspect the latest repository state.
2. Read AGENTS.md.
3. Read DESIGN.md.
4. Read the relevant section of plan.md.
5. Inspect existing implementation.
6. Determine whether another device or branch may already be implementing related work.

Do not overwrite or duplicate existing work.

---

# PROJECT OBJECTIVE

Build a premium AI-powered bathroom design platform that uses REAL KOHLER products and verified product information.

A user should be able to provide:

* Bathroom dimensions
* Bathroom photographs
* Floor plans
* Room elements
* Budget
* Preferred style
* Functional preferences
* Natural-language requirements

The system should then:

* Understand the user's requirements.
* Retrieve relevant real KOHLER products.
* Check physical and functional constraints.
* Create compatible product combinations.
* Generate bathroom layouts.
* Allow interactive editing.
* Allow conversational design changes.
* Recalculate budget.
* Provide product information.
* Save and share completed designs.
